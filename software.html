Active R&D · Core Operational Atlas55kk/Ai-vision (Private Repo)

Ai-vision: Real-Time Delta-Frame Visual AI Bridge for CAD, CAE & Game Engines

Repository: Private Development Build · Experimental Benchmarking Phase
  • Engineered a working core visual perception pipeline streaming desktop viewports at 24–30+ FPS by isolating temporal pixel-level deltas (frame-to-frame change detection) rather than transmitting full redundant screenshots.
  • Formulated a token-compressed spatial data representation to minimize LLM/VLM context consumption while preserving fine-grained UI and 3D viewport geometry states.
  • Designed an API execution bridge with privacy/security masking layers to autonomously drive complex engineering workflows across 3D CAD design, Ansys / CAE simulation setups, and the Godot Game Engine.
