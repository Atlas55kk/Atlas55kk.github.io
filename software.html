GEO: 3D Parametric Wireframe Representation Engine

github.com/Atlas55kk/GEO
  • Engineered an open-source 3D parametric geometry visualizer parsing declarative JSON schemas for spatial reasoning and CAD pre-visualization.
  • Acts as an intelligent bridge between high-level reasoning and CAD solid model script generation, verifying geometric topology before dispatching compute-intensive solid models.
  • Implemented a dual-mode architecture supporting a standalone desktop GUI in Python and a lightweight serverless browser deployment.
